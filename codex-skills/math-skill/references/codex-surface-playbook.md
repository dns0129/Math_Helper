# Codex 工具与输入

从技能路径定位资源，而不是假设用户当前目录就是技能目录。使用可用的 shell 执行工具运行本地 Python。无执行能力时继续推导，明确本次没有脚本验算。

用户附图可直接视觉阅读。磁盘图片使用可用的图像查看工具；PDF 先提取文本或将目标页渲染为图像，再核对公式。文件不在可访问路径时，说明缺失的输入。

图片模糊时先检查放大视图。只有歧义影响答案时才请求澄清；不能根据几何草图的外观自行假设长度相等、垂直或按比例绘制。

图像增强脚本的成功仅说明生成了增强图，不说明读题正确。生成图像后实际查看，复核符号和题目范围。

回答按题目需要组织：题意及条件、公式与理由、关键推导、结果、实际完成的验算。避免为了符合模板扩写简单题。
